# Independent Engineering Review Dossier

Purpose: define the evidence package needed for an independent engineering
assessment of the normalized bracket workflow case. This folder does not contain
an independent review and does not claim certification.
It also includes a dimensional candidate case with real units, material
assumptions, loads, and acceptance criteria so an independent assessor can evaluate whether
the normalized manuscript case is mechanically meaningful.

## Files

- `review_dossier.md`: case definition and evidence checklist for engineering assessment.
- `dimensional_bracket_case.json`: structured dimensional assumptions for a
  future real-load/material review.
- `dimensional_case_review_packet.md`: assessment-facing explanation of the
  dimensional candidate case.
- `acceptance_checklist.md`: review checklist for model validity boundaries.
- `review_signoff_template.md`: template for reviewer comments and decision.
- `validate_review_packet.py`: verifies that required dossier files are present.

## Reporting Boundary

Until an independent engineering assessor completes the sign-off template, the manuscript
must describe the bracket as a normalized workflow case, not a certified
engineering design.
